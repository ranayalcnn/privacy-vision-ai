# Data Processing Inventory

| Field | Description |
|---|---|
| Processing purpose | Real-time face detection and privacy-preserving video analytics |
| Data source | Camera or authorized video stream |
| Personal data risk | Faces, body appearance, clothing, and movement |
| Processing action | Detection followed by blur, mosaic, color shield, or fail-safe blur |
| Storage | Anonymized output only; original frames are not stored |
| Audit data | Timestamp, event, frame number, face count, and mode |
| Access | Authorized development or operations personnel |
| Retention | Audit records retained according to organizational policy |
| Security measures | Bounded memory queue, fail-safe output, access control, and audit logging |
