# YOLO Face Blur & Person Tracking System

## 📌 Overview

YOLO Face Blur & Person Tracking System is a real-time computer vision application designed to detect human faces, anonymize detected faces using Gaussian Blur, and track individuals across video frames with unique IDs.

The project combines **YOLO-based object detection**, **face detection**, and **multi-object tracking** techniques to create a privacy-preserving video analytics pipeline.

The system can be used in scenarios where automated video analysis is required while maintaining personal privacy, such as security systems, smart cameras, and industrial monitoring applications.

---

## 🚀 Features

- Real-time face detection using YOLO-based deep learning models
- Automatic face anonymization with Gaussian Blur
- Person detection and tracking with persistent IDs
- Multi-object tracking across consecutive video frames
- Modular project architecture
- Video-based analysis support
- Privacy-preserving computer vision pipeline
